Build the desktop app

Twenty themes. One WezTerm export.

Mac27, Apple, Tokyo Night, Catppuccin, Dracula, Nord and more. teryon themes --export wezterm NAME gives your terminal the same palette.

Up and running in minutes.

Requires Rust, macOS or Linux, and a UTF-8 terminal.

Build and try it locally cargo build --release --locked ./target/release/teryon connect local --workspace hello
Install on your Mac miniEnable Remote Login, set up SSH keys, then: ./scripts/install.sh ./target/release/teryon
Connect from your MacBook teryon doctor you@mini.local teryon connect you@mini.local --workspace fluxvm
Want the desktop app? cargo build --release --features desktop --locked teryon desktop you@mini.local --workspace fluxvm

Press Ctrl+Space then ? for help. Ctrl+Space → d detaches; your shells keep running.
